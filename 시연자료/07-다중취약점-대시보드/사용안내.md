# 다중 취약점 대시보드 시연용

1. 압축을 풀어 주세요.
2. ai-work-security에서 새 검사 시작 → 폴더 선택을 누르세요.
3. 이 안내 파일 옆의 **업무포털** 폴더를 선택하고 검사하세요.
4. 수정 필요 항목을 클릭하고, 상세의 다음 위치 화살표로 같은 유형의 여러 위치를 확인하세요.
5. 추가 확인 탭도 확인하세요.

실제 회사 소스나 개인정보가 아닌 인위적으로 만든 시연 자료입니다. 키는 무작위로 생성한 문자열이며 어떤 서비스에서도 발급받지 않았습니다. 이 코드 자체를 실행하거나 서비스에 배포하지 마세요. 코드를 검사기에 읽히는 용도입니다.

시연을 위해 실제 코드 구조로 작성했습니다. tests, samples, demo-data 같은 경로에 옮기면 예제 항목으로 분류될 수 있으므로 압축 안의 폴더 이름을 유지하세요. 검사기의 판단 기준을 변경하지 않았습니다.

유형: 화면 비밀키, 서버 비밀키, 검색 명령에 입력값 연결, 서버 명령 실행, 자료 쓰기 전체 허용, 입력값 코드 실행. 각 유형마다 업무별 5곳을 넣었습니다.

## 현재 버전 검증 결과
- 검사 파일: 32개
- 수정 필요: 30곳 / 6개 묶음
- 추가 확인: 1곳 / 1개 묶음
- 결과에 키 문자열 원문이 포함되지 않는 것 확인
- 실제 보안 사고가 아니라 의도적으로 만든 코드 패턴 검사 결과입니다.
